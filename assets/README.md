# Screenshots

This directory should contain screenshots of the dashboard for the project submission.

## Required Screenshots

1. **desktop-dashboard.png** - Full desktop view of the dashboard
2. **mobile-dashboard.png** - Mobile responsive view
3. **dark-mode.png** - Dark mode theme view

## How to Take Screenshots

1. Start the development server: `npm run dev`
2. Open http://localhost:3000 in your browser
3. Take screenshots at different screen sizes:
   - Desktop: 1920x1080 or larger
   - Mobile: Use browser dev tools to simulate mobile view
   - Dark mode: Toggle the theme button

## Screenshot Guidelines

- Use high resolution (at least 1920x1080 for desktop)
- Ensure all charts and data are visible
- Show the complete dashboard layout
- Include both light and dark themes
- Demonstrate responsive design on mobile

## File Naming

- `desktop-dashboard.png` - Main desktop view
- `mobile-dashboard.png` - Mobile responsive view  
- `dark-mode.png` - Dark theme view
